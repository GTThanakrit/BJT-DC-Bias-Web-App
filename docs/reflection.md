## สิ่งที่สร้าง

Flask Web App หลายไฟล์สำหรับคำนวณ DC Bias ของ NPN BJT แบบ voltage-divider:
ฟอร์มรับ VCC, R1, R2, RC, RE, β, VBE แล้วให้ Python คำนวณ VTH, RTH, IB, IC, IE,
VB, VE, VC, VCE พร้อมหน่วยและ Operating Region

## สิ่งที่ตรวจสอบแล้ว

- ผลตรงกับการคำนวณมือ (VCE = 8.052 V, IC = 1.230 mA) ตาม `docs/validation.md`
- Automated tests 21 ตัวผ่านทั้งหมด (13 engineering + 8 HTTP)
- กรอกค่าผิด (R1 = 0, ตัวอักษร, ช่องว่าง) แล้วเว็บแจ้ง error โดยไม่ล่ม
- กรณี Cutoff และ Saturation มี warning และไม่รายงานว่าแบบจำลองใช้ได้
